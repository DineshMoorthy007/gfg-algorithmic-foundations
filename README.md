# gfg-algorithmic-foundations

## Project Overview

`gfg-algorithmic-foundations` is a structured, day-by-day record of problem-solving practice from GeeksforGeeks.  
The repository is designed to build strong fundamentals in core data structures, basic algorithms, and disciplined logical reasoning through consistent implementation and review.

## Objectives

- Strengthen understanding of foundational data structures and algorithmic patterns.
- Practice stepwise problem decomposition and clean solution design.
- Develop the habit of evaluating time and space complexity for each solution.
- Improve logic-building through daily, incremental coding practice.
- Maintain a reliable technical archive of solved problems for revision and interview preparation.

## Repository Architecture

The repository follows a strictly chronological, lexicographically sortable directory convention:

- `Day_001`
- `Day_002`
- `...`
- `Day_010`
- `Day_100`

## Documentation Standard

Each day folder is intended to be educational and easy to review later. The related README should explain:

- the problem in simple terms,
- the core algorithm or technique used,
- why the method works,
- the time and space complexity,
- the language or languages used,
- and the file mapping for the solution.

## Algorithms and Methods Used So Far

- `Day_001` uses an in-place two-pointer swap to reverse an array.
- `Day_002` uses a write-pointer compaction method in Python and a swap-based in-place method in Java to move all zeros to the end.
- `Day_003` uses a single-pass two-variable scan to find the second largest distinct element in an array.
